# Minimo Launcher (Clean-up Edition)

A minimal, distraction-free Android launcher built to help you use your phone less and focus more. This is a cleaned-up fork of [Minimo Launcher] with unnecessary clutter removed and a new digital wellbeing feature to help prevent phone addiction.

## Why this fork?
Most launchers push you to spend more time on your phone with busy home screens, widgets, and constant visual noise. This version goes the other way: fewer distractions, a calmer interface, and tools that make you stop and think before you open an app.

## What's changed
### 🧹 Clean-up
- Removed cluttered and unnecessary UI elements
- Removed unused features, code, and resources
- Simplified settings and menus
- Reduced app size and improved performance

### 📵 New: Anti-addiction feature
- Launch delay improved version.
- "Shows a short pause screen before opening distracting apps"
- "Helps you break the habit of mindless scrolling"
- New motivation thought features.

## Features
- Clean, text-based home screen
- Fast app search and launch
- Improved bottom search search if enabled
- Lightweight with low battery and RAM usage
- No ads, no tracking, no unnecessary permissions
- Dubble tap on launch
- New Jost font
- New seprate select of dark and light theme mode
- Open source
  

Less things. Less addictive
